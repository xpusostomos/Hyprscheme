Hyprscheme TODO — missing Scheme API, compiled from the wiki conversion
(Sept 2026). Every entry was hit while writing the Scheme wiki; page
references point into Hyprscheme.wiki. Suggested hl- names are proposals.

== 1. CONFIG API ==
IMPLEMENTED 2026-09-17 (commit 99ef2e9): hl-config / hl-config-get — set
and get config options from scheme with full propagation (scratch lua
state over the config manager's own typed parsers; numbers, strings,
bools, arrays, alists; typed error messages). Remaining in this section:
IMPLEMENTED 2026-09-17 (commit 100b8b8): hl-monitor (22 fields, live
verified: transform/scale apply, reserved commits — nested-display
caveat is layer-driven), hl-curve (bezier+spring), hl-animation
(nodes with curve/style validation), hl-permission (startup-only, like
upstream). Section 1 COMPLETE.

== 2. DISPATCHER SURFACE (the general "do things" layer) ==
IMPLEMENTED 2026-09-17 (commit cd9abc7): the core surface now exists as
direct hl- functions — focus (workspace/monitor/direction/last/urgent),
window move/swap/cycle/resize/center (px + direction), pin/pseudo/kill/
signal/zorder/set-prop/tag/clear-tags, float/fullscreen with explicit
action+mode, fullscreen-state, group API (toggle/cycle/index/move/lock),
workspace rename/toggle-special/move-to-monitor/swap-monitors, cursor
move/corner, dpms, pass, send-shortcut, send-key-state, event, global,
force-idle, renderer-reload, release-input-capture, mouse drag/resize,
layout-msg send. All verified live. Remaining from this section:
  - move a window directly to another MONITOR (moveToMonitor takes a
    workspace; no window-to-monitor action)
  - workspace change_id
  - window-selector targeting for pass/send-shortcut (background windows)
  - exec_raw, exec-with-rules
  - hl-window-fullscreen-handler accessor
  - submap setSubmap via CA::setSubmap (scheme has enter/exit already)

== 3. RULES API ==
IMPLEMENTED 2026-09-17 (commit 37f936e): hl-window-rule / hl-layer-rule
(match/effect model over the rule engine, named-rule reuse, enable/
disable handles, anchored-regex matches) and hl-workspace-rule (all 15
fields + layout_opts over the workspace rule manager). Verified live:
float/workspace/opacity effects, disable, reload re-registration,
hyprctl workspacerules visibility, typed errors. Remaining:

  - exec-rule integration (hl.exec-with-rules rides on markAsExecRule)

hl-on-config-reloaded (fires on the reload AFTER registration — register in
the config file) — plus window events: title, class, urgent, pin,
fullscreen, move-to-workspace, active, minimize (w state). Remaining:

  - workspace.special_active/created/removed/move_to_monitor

  - layer.opened/closed, screenshare.state, input.keyboard.key (low)

    reset after a dispatch)
  - exclusive per-device binds ('device-inclusive #f polarity)
  - gestures: hl-gesture API + live gesture callbacks (whole page gap)

== 7. TIMERS ==
