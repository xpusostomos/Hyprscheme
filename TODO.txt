Hyprscheme TODO — genuinely outstanding items
(consolidated 2026-09-17 after the tail sweep). The large API chunks
are all implemented and verified — config, actions/dispatchers, events,
rules, queries, notifications, timer handles, exec variants, gestures,
watchdog (see git log and the wiki's per-page state). What follows is
what is still missing or unverified. Suggested hl- names are proposals.

== BINDS ==
auto_consuming flag + the return-{ok=false} protocol — passing the
  keypress to the window when the action didn't succeed ('transparent
  / 'non-consuming cover related pass-through; this one needs a result
  channel from the bind callback). Suggested: 'auto-consuming option.
Unbind by key — remove all binds registered on a key (upstream
  hl.unbind("key")). Suggested: (hl-unbind-key "SUPER" "L").

== ACTIONS / DISPATCHERS (small leftovers) ==
Move a window directly to another MONITOR — CA::moveToMonitor takes a
  workspace; there is no window-to-monitor action.
Workspace change_id — CA::changeWorkspaceID.
Submap setSubmap — CA::setSubmap exists; scheme already has enter/exit;
  decide whether a scheme-facing switch-by-name is wanted.
Per-effect rule handles — rule effects are raw-string based today;
  per-effect get/set may be wanted (mirrors upstream's set_prop).

== DEVICES ==

== GESTURES ==

== TOOLING ==

README refresh — the config/rules/queries/gestures/watchdog chunks

== WATCHDOG NOTES (no action — documented limits) ==
Recovery is out of scope by design (a Chez call cannot be killed
safely); the detector logs only. The notification overlay aborts when
poked from a side thread (verified, signal 6) — keep the watchdog
log-only, or schedule notifications from the MAIN loop if ever wanted.
