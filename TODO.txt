Hyprscheme TODO — missing Scheme API, compiled from the wiki conversion
(Sept 2026). Every entry was hit while writing the Scheme wiki; page
references point into Hyprscheme.wiki. Suggested hl- names are proposals.

== 1. CONFIG API (the big one — most wiki pages blocked on it) ==
hl-config — set config options from Scheme: nested form and flat
  ("path.option" = value) form; runtime changes from hyprctl scheme.
  Needed by: config-options, animations, dwindle/master/scrolling-layout,
  performance, tearing, xwayland, permissions (enforce_permissions), device
  binds (drag_threshold), custom-layouts (layout selection!).
  Companion read side: hl-config-get ("general:gaps_in" etc.) — needed for
  option-aware binds (see code-snippets "smart gaps", "toggle animations").
hl-monitor — monitor rules: mode (incl. modeline strings), scale,
  position, transform, reserved area, colors (cm/sdr_eotf/bitdepth/icc/
  sdrbrightness/sdrsaturation), mirror, vrr, disabled, HEADLESS outputs.
  Needed by: monitors + 4 sub-pages, performance, virtual-gpu, xwayland.
hl-animation / hl-curve — animation + bezier/spring curve
  declarations. Needed by: animations page.
hl-permission — permission rules (binary/type/mode regexes).
  Needed by: permissions page.

window move/swap/cycle/resize/center (px + direction), pin/pseudo/kill/
signal/zorder/set-prop/tag/clear-tags, float/fullscreen with explicit
action+mode, fullscreen-state, group API (toggle/cycle/index/move/lock),

force-idle, renderer-reload, release-input-capture, mouse drag/resize,

  - submap setSubmap via CA::setSubmap (scheme has enter/exit already)

== 5. QUERIES / SELECTORS ==

  - hl-active-workspace, hl-workspace-info (object w/ properties),

== 6. BINDS / SUBMAPS ==
  - 'submap-universal bind option (bind active in every submap)
  - auto-chain submap: optional follow-up arg to hl-submap (next submap or
    reset after a dispatch)
  - exclusive per-device binds ('device-inclusive #f polarity)
  - gestures: hl-gesture API + live gesture callbacks (whole page gap)

== 7. TIMERS ==
  - timer handles with enable/disable + enabled? (pausable named timers;
    the state-flag workaround works but is clunky)

== 8. NOTIFICATIONS ==
  - hl-notify (text/timeout/icon/color/font-size); hyprctl notify via
    hl-exec is the workaround documented in the wiki

== 9. EXEC ==
  - exec-with-rules (spawn with window-rule effects, e.g. float a spawned
    game window) — dispatchers, window-rules, code-snippets
  - hl-exec-raw (no sh -c)

== 10. TOOLING ==

    the compositor — upstream Lua has per-callback timeouts) — core wiki page
  - Interactive REPL (hyprctl repl equivalent; hyprctl scheme is one-shot)
  - Editor integration notes: a scheme stub/skeleton for completion parity
    with upstream's Lua stubs (naming-conventions mentions plain editors)
