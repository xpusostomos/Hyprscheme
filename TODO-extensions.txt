  The implementation is in core (hl-workspace-groups + hl-group record
  family — see TODO.txt). This file was the wrong home for it all along;
  the entry dies here.

== CROSS-RELOAD STATE (accepted extension, 2026-09-22) ==
hl-state-set!/ref/keys/remove! — a Hyprscheme extension beyond parity:
  upstream Lua has NO cross-reload state (its whole Lua world is rebuilt
  per reload). Justification: without it a Scheme config has no way to
  keep ANYTHING across a reload (files aside), and the test suite leans
  on it (api-unload flag, proto-ticks). Per Chris: fine for tests, not
  to be leaned on by core features. Remove! added 2026-09-22; docs in
  scheme-utilities.md ("Cross-reload state", extension status stated).
